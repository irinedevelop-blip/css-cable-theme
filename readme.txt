=== CSS Cable ===
Тема WordPress + WooCommerce + Elementor для сайта «ЦСС Кабель».

УСТАНОВКА
1. Внешний вид → Темы → Добавить → Загрузить тему → css-cable.zip → Активировать.
2. Установите плагины WooCommerce и Elementor (бесплатный).
3. Внешний вид → Генератор главной → «Сгенерировать главную».
   Будут созданы: главная в Elementor, категории товаров, страницы
   (О компании, Новости, Контакты, Калькулятор веса, Сертификаты), меню, демо-новости.
4. Настройки → Постоянные ссылки → «Название записи» → Сохранить.

ГДЕ ПРАВИТЬ
- Главная: Страницы → Главная → «Редактировать в Elementor». Виджеты в панели, категория «CSS Cable»:
  CSS: Первый экран / Продукция / Поставки (слайдер) / Новости. Все тексты, кнопки, картинки,
  слайды, цвета, шрифты и отступы редактируются в панели виджета. Можно добавлять любые
  стандартные виджеты Elementor между секциями.
- Видео в шапке: Внешний вид → Настроить → «CSS Cable: настройки темы» → «Видео-шапка»
  (фоновое MP4 без звука, постер, ссылка для кнопки ▶ — YouTube/Vimeo/MP4, где показывать).
  В теме лежит демо-видео из фото макета — замените на своё.
- Контакты, WhatsApp, адреса, цвета, корзина в меню:
  Внешний вид → Настроить → «CSS Cable: настройки темы».
- Логотип: Внешний вид → Настроить → Свойства сайта.
- Новости = обычные Записи (миниатюра = фото карточки).
- Товары WooCommerce: без цены показывается «Цена по запросу» и кнопка «Оставить заявку».
  Поле «Вес 1 км, кг» (вкладка «Основные») используется калькулятором.

ШОРТКОДЫ
[cssc_weight_calc]       — калькулятор веса кабеля
[cssc_request_button]    — кнопка «Оставить заявку» (открывает форму)
Любая ссылка с адресом #zayavka открывает форму заявки. Заявки уходят на e-mail из настроек темы
(для надёжной отправки рекомендуется плагин SMTP, например WP Mail SMTP).

Шаблон Elementor в JSON: Внешний вид → Генератор главной → «Скачать JSON-шаблон».

АНИМАЦИЯ (v1.2)
Внешний вид → Настроить → «CSS Cable: настройки темы» → «Анимация»:
плавный инерционный скролл (Lenis, MIT), интро первого экрана, появление блоков при прокрутке,
параллакс видео и слайдов, липкое меню, курсор-кольцо. Каждую опцию можно выключить.
Для посетителей с включённым «уменьшением движения» в системе анимация отключается автоматически.
В редакторе Elementor всё показывается сразу, без анимации.
